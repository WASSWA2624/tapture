# 24 — The minimal backend

The minimal backend of specification Part XI. It is **required**: accounts, authentication, roles, AI functionality and provider-key custody — the five things a single device cannot supply for itself, and nothing more. The change relay (§72) is the one optional capability inside this phase; every other part is part of the MVP. Required to exist, never required to be reachable (§70.4).
